# MVP 浏览器验收（2026-09-15）

环境：Codex 内嵌真实浏览器，连接本机 FastAPI `127.0.0.1:8767`，显式 historical_demo。通过 UI 操作而非调用页面内部状态完成。

## 已验证

1. 输入页点击杭州→上海样例，实际填入杭州、乌镇、西塘古镇、南浔古镇、上海；保留原顺序。
2. 点击下一步，进入真实 Trip 确认页；五组候选 radio 均未预选，显示各 POI 名称、城市、完整地址。
3. 逐个选中候选，点击确认并优化，页面显示杭州→南浔→乌镇→西塘→上海，3小时36分、230.0公里、节省49分钟/63.9公里。底层精确值由 Python 回归校验。
4. 选择第3段，刷新后仍为第3段，起终点为乌镇→西塘。独立新标签直接打开同一 Trip URL，也能恢复同一结果与段号，不重新输入。
5. 再切到第4段，当前路段按钮恰好一个，标签与所选段同步。没有监听后台事件来自动推进进度。
6. 点击复制链接，页面显示“已复制”；URL 构造与无令牌由 JS 单元测试核验。浏览器工具剪贴板读取返回空，因此未宣称跨应用粘贴实测通过。
7. 浏览器实际检查 390×844 手机宽度与 1280×900 桌面宽度；手机结果页 document.scrollWidth=390，main.width=390，无横向溢出；输入页正常换行。普通视口截图视觉检查通过。工具 fullPage 拼接截图出现重复片段，不将拼接异常记为页面内容重复（DOM 始终4段）。
8. 地图/导航 Key 缺失时显示明确状态，路线、分段、分享、复制目的地入口保持可用。新结果标签的 console error 为空。
